# Name: load_data (facebook.csv)
# Purpose: read the file and store every post as a list of the different fields,returning a list of all posts
# Parameters: filename (the name of the data file, in this case facebook.csv)
# Return: data (a list of lists, one per post)
    1. Read file (facebook.csv)
    2. Create an empty list called data
    3. Open the file
    4. Paste the list from (facebook.csv) into the list named data and seperate by category
    5. For each line in the file:
         split the line by ";" and append it to data
    6. Return data


# Name: show_menu
# Purpose: show the user their options and return their choice
# Parameters: none
# Return: user choice (#1-5)
    1. Print the 5 options:
        1. Likes vs shares
        2. Engaged users chart
        3. Post type with most average likes
        4. Which post type is most/least likely to be paid
        5. Quit
    2. Ask the user to enter a number
    3. If the number is not 1-5, ask again
    4. Return their choice


# Name: likes_vs_shares
# Purpose: for a chosen post type, compare likes vs shares for each post and write the results to a file
# Parameters: data (the list of posts from load_data)
# Return: nothing
    1. Ask the user which type: Photo, Status, Link, or Video
        Keep asking until they enter a valid type
    2. Ask the user for an output filename
    3. Open that file for writing
    4. For each post in data:
        if the post type doesn't match, skip it
        calculate difference = likes - shares  (indexes 16 and 17)
        classify the difference:
               > 100   -  "significantly more likes"
               >= 25   -  "more likes"
               > -25   -  "about the same"
               >= -100 -  "more shares"
               else   -  "significantly more shares"
        write the post number, likes, shares, and label to the file
    5. Print a confirmation message


# Name: engagement_chart
# Purpose: count how many posts are low, moderate, and high engagement and display a bar chart
# Parameters: data (the list of posts from load_data)
# Return: nothing

    1. Set the three counters to 0: low = 0, moderate = 0, high = 0
    2. For each post in data:
         get engaged users (index 9, convert to int)
         if less than 100:        low += 1
         elif 100 up to 400:      moderate += 1
         else:                    high += 1
   3. Build a bar chart:
         categories = ["Low", "Moderate", "High"]
         counts     = [low, moderate, high]
   4. Add a title and axis labels
   5. Display the chart

# Name: avg_likes_by_type
# Purpose: Find which post type has the highest average likes
# Parameters: data (the list of posts from load_data)
# Return: nothing
   1. Create a dictionary to track total likes and post count per type
   2. For each post in data:
         add its likes (index 16) to the matching type in the dictionary
   3. For each type, divide total likes by post count to get the average
   4. Print each type and its average
   5. Print which type had the highest average


# Name: payment_post
# Purpose: finds which post type is most and least likely to be paid
# Parameters: data (the list of posts from load_data)
# Return: nothing
   1. Create a dictionary to track paid count and total count per type
   2. For each post in data:
         get post type (index 1) and paid status (index 6)
         add to the matching type in the dictionary
   3. For each type, calculate:
         paid percentage = (paid count / total count) * 100
         print the type and its paid percentage
   4. Print which type is most likely to be paid
   5. Print which type is least likely to be paid


# Name: main
# Purpose: Start the program, load the data, and run the menu loop
# Parameters: none
# Return: nothing
   1. Call load_data() and store the result in data
   2. Loop forever:
         call show_menu() and store the result in choice
         if choice == 1: call likes_vs_shares(data)
         if choice == 2: call engaged_chart(data)
         if choice == 3: call avg_likes_by_type(data)
         if choice == 4: call custom_question(data)
         if choice == 5: print "Goodbye!" and stop loop
